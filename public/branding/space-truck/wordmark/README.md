## Quando usar horizontal ou vertical?
- **horizontal** → espaços largos (header, banner, rodapé)
- **vertical** → espaços altos, quadrados ou compactos

## Quando usar branco ou preto?
- **branco** → fundo escuro / dark background
- **preto** → fundo claro / light background
