# Space Truck / reference

Material de referência visual para a marca Space Truck: guias de estilo, paleta de cores, tipografia, exemplos de uso correto/incorreto e outros materiais de apoio.

## Escopo
- Guias visuais e manuais de marca
- Paleta de cores oficial
- Tipografia oficial
- Exemplos de uso correto e incorreto do logo
- Mockups e materiais institucionais de referência

## Arquivos esperados
> Os arquivos de referência serão adicionados manualmente conforme disponibilidade.

## Observação
Esta pasta é apenas de **apoio e consulta**. Não contém os assets oficiais de marca.
Os arquivos de marca oficiais ficam nas pastas irmãs: `logo/`, `simbolo/`, `wordmark/`, `slogan/`, `icone/`.
