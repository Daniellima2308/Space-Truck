# Space Truck / logo

Armazena as versões de **logo completo** da marca Space Truck.

## Composição
`logo = símbolo + wordmark`
`logo com slogan = símbolo + wordmark + slogan`

## Quando usar branco ou preto?
- **branco** → fundo escuro / dark background
- **preto** → fundo claro / light background
