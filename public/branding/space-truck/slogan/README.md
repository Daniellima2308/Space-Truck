## Diferença entre slogan e logo
- **slogan** = apenas a frase institucional (ex.: "Gestão para caminhoneiros")
- **logo com slogan** = símbolo + wordmark + slogan (arquivo em `logo/`)

## Quando usar branco ou preto?
- **branco** → fundo escuro / dark background
- **preto** → fundo claro / light background
