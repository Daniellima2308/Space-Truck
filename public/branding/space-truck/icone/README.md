# Space Truck / icone

Armazena as versões de **ícone** da marca Space Truck, otimizadas para uso como ícone de aplicativo, atalhos e elementos compactos.

## Composição
`icone = símbolo dentro de moldura quadrada/arredondada`

## Diferença entre ícone e símbolo
- **ícone** = símbolo dentro de uma moldura/container (fundo definido), formatado para uso como ícone de app
- **símbolo** = apenas o elemento gráfico isolado, sem moldura ou fundo definido (arquivo em `simbolo/`)

## Usos típicos do ícone
- Ícone do aplicativo móvel / PWA
- Atalho na tela inicial
- Notificações e tray
