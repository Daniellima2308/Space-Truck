# Space Truck / simbolo

Armazena o **símbolo isolado** da marca Space Truck (sem wordmark e sem slogan).

## Composição
`simbolo = símbolo sozinho, sem texto`

## Diferença entre símbolo e logo
- **símbolo** = apenas o elemento gráfico/ícone, sem texto
- **logo** = símbolo + wordmark "SPACE TRUCK"

## Quando usar branco ou preto?
- **branco** → fundo escuro / dark background
- **preto** → fundo claro / light background
