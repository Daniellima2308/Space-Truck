# Bino / poses

Poses derivadas do personagem Bino para uso em diferentes contextos do app.

## Arquivos esperados
> Os PNGs ainda não estão no repositório. Serão adicionados manualmente.

Organize os arquivos de poses seguindo a convenção:
`bino-pose-[nome].png`

Exemplos:
- `bino-pose-apontando.png`
- `bino-pose-acenando.png`
- `bino-pose-pensando.png`

## Observação
As sub-pastas legadas (`bino-1/`, `bino-2/`, `bino-3/`) foram mantidas como referência histórica.
