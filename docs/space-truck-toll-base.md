# Base própria de pedágios do Space Truck

Este documento marca a branch de trabalho da primeira base própria de pedágios do Space Truck.

Escopo inicial aprovado:

- substituir a dependência direta de API externa de pedágio na Análise de Frete;
- manter nomes neutros e oficiais no código;
- preservar a separação entre base de dados, motor de cálculo e interface;
- evoluir o cálculo para usar geometria da rota antes da integração final.

Esta branch altera o comportamento em tempo de execução no fluxo de cálculo de pedágio.
