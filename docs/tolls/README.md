# Documentação da base de pedágios

Use esta pasta para relatórios, resumos e observações sobre a base própria de pedágios do Space Truck.

Esta pasta é para documentação humana. O app não deve importar diretamente estes arquivos.

## Nomes recomendados

- `space_truck_toll_base_summary.md`
- `space_truck_toll_base_audit_report.pdf`
- `space_truck_toll_base_quality_notes.md`

## Sugestões de conteúdo

- total de linhas analisadas;
- total de praças usadas no cálculo;
- linhas fora do cálculo;
- critérios de inclusão e exclusão;
- alertas conhecidos;
- correções aplicadas;
- fontes consultadas;
- data da revisão.

No código do app, mantenha nomes neutros como `Space Truck`, `space_truck_toll_base`, `tollPoints.ts` e `tollEngine.ts`.
